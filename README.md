# 안전 타이밍 챌린지 — GitHub Pages + Firebase 랭킹

직원들이 카카오톡으로 게임 URL을 받아 접속하고, 닉네임으로 5라운드 타이밍 게임에 참여한 뒤 **합산 점수**로 전체 랭킹을 보는 이벤트용 웹게임입니다.

- **플레이 방식**: 5번의 타이밍 기회
- **게임 룰**: 양쪽 바가 중앙 안전 위치에 들어올 때 터치
- **점수 방식**: 각 라운드 0~100점, 소수점 3자리, **합산 최대 500점**
- **랭킹 방식**: 같은 브라우저/같은 익명 사용자 기준 **최고 합산 점수 1개만 저장**
- **보호구 연출**:
  1. 낙하물 위험 → 안전모
  2. 발에 물건 떨어짐 → 안전화
  3. 추락 위험 → 안전대
  4. 감전 위험 → 절연 장갑
  5. 눈 비산물 위험 → 보안경 (`삐싱!`)
- **마무리 문구**: `모두의 안전을 지켜주셔서 감사합니다`

---

## 파일 구성

- `index.html` : 게임 화면
- `style.css` : 전체 UI 스타일
- `script.js` : 게임 로직, 점수 계산, 랭킹 처리
- `firebase-config.js` : Firebase 웹 앱 설정값 입력 파일
- `firestore.rules` : Firestore 보안 규칙
- `assets/ls-logo.png` : 헤더용 로고
- `assets/ls-mascot.png` : 인트로용 마스코트 이미지

## 1) Firebase 설정 (무료 Spark 플랜)

이 게임은 **GitHub Pages + Firebase** 조합으로 무료 운영이 가능합니다.

### A. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 접속합니다.
2. **프로젝트 추가**를 눌러 프로젝트를 만듭니다.
3. 요금제는 **Spark(무료)** 를 선택합니다.

### B. 웹 앱 등록
1. 프로젝트 설정(톱니바퀴) → **내 앱** → `</>` 웹 앱 추가
2. 앱 이름 입력 후 등록
3. 표시되는 설정값 중 아래 4개를 복사합니다.
   - `apiKey`
   - `authDomain`
   - `projectId`
   - `appId`
4. 이 폴더의 `firebase-config.js`에 붙여 넣습니다.

예시:
```js
window.FIREBASE_CONFIG = {
  apiKey: "...",
  authDomain: "...firebaseapp.com",
  projectId: "...",
  appId: "..."
};
```

### C. 익명 로그인 켜기
1. Firebase 콘솔 → **Authentication** → **Sign-in method**
2. **Anonymous(익명 로그인)** 사용 설정

이렇게 하면 참여자는 로그인 화면 없이 자동으로 접속합니다.

### D. Firestore Database 만들기
1. Firebase 콘솔 → **Firestore Database** → 데이터베이스 만들기
2. 지역 선택 후 생성
3. **Rules** 탭으로 가서, 이 프로젝트의 `firestore.rules` 내용을 전체 붙여넣고 **게시**합니다.

> 주의: 테스트 모드의 `allow read, write: if true;` 공개 규칙을 그대로 쓰지 마세요.

## 2) GitHub Pages 배포

### A. GitHub 저장소 만들기
1. GitHub에서 새 저장소를 만듭니다. (공개 저장소 권장)
2. 이 폴더의 파일 전체를 업로드합니다.

### B. Pages 켜기
1. 저장소 → **Settings** → **Pages**
2. **Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/(root)`
3. 저장 후 1~3분 정도 기다립니다.

그러면 아래 같은 주소가 발급됩니다.

```text
https://사용자명.github.io/저장소이름/
```

이 주소를 **카카오톡에 공유**하면 여러 사람이 같은 게임에 접속할 수 있습니다.

## 3) 이벤트 운영 방법 추천

### 가장 간단한 운영 흐름
1. GitHub Pages 주소 생성
2. 카카오톡 단체방에 URL 공유
3. 참가자가 닉네임 입력 후 플레이
4. 게임 종료 시 최고 점수 자동 저장
5. 모든 참가자가 같은 TOP 10 랭킹 확인

### 추천 문구 예시
```text
[안전 타이밍 챌린지]
아래 링크로 접속해서 5라운드 타이밍 게임에 참여해주세요!
닉네임으로 랭킹이 집계됩니다.

https://사용자명.github.io/저장소이름/
```

## 4) 점수/랭킹 방식

- 각 라운드 0~100점
- 소수점 3자리까지 저장
- 5라운드 합산으로 최종 점수 산출
- 최대 총점: `500.000`
- 같은 사용자는 **최고 점수만 갱신**
- 랭킹은 **TOP 10** 표시
- 동점 가능성은 매우 낮지만, 같은 점수가 발생할 경우 Firestore 정렬상 먼저 기록된 쪽이 먼저 보일 수 있습니다.

---

## 5) 체험 모드

`firebase-config.js`를 비워두면 게임은 **체험 모드**로 동작합니다.

- 게임 플레이는 정상 가능
- 랭킹은 **현재 브라우저의 localStorage**에만 저장
- 다른 사람과 공유되는 랭킹은 아님

즉, Firebase 연결 전에도 화면 확인과 사전 테스트가 가능합니다.

## 6) 주의사항

이 버전은 **재미로 참여하는 이벤트용**으로 가장 단순한 구조입니다.

- 닉네임이 중복될 수 있습니다.
- 브라우저를 바꾸면 별도 참가자로 기록될 수 있습니다.
- 개발자 도구를 이용한 고급 조작을 완전히 막지는 못합니다.
- 경품 지급용 공식 대회라면 서버 검증이 추가로 필요합니다.

하지만 **사내 가벼운 참여형 이벤트**에는 충분히 적합한 구조입니다.

## 7) 수정 포인트

### 게임 문구 바꾸기
`script.js`의 `HAZARDS` 배열에서 각 라운드 제목과 설명을 수정하세요.

### 속도 조절
`script.js`의 `SPEEDS` 배열을 조정하면 각 라운드 난이도를 바꿀 수 있습니다.

### 디자인 수정
`style.css`에서 색상, 버튼 모양, 레이아웃을 수정할 수 있습니다.
