# LS전선 안전 타이밍 챌린지 v2

**아이폰 세로 화면, 스크롤 없는 5라운드 게임**, GitHub Pages 배포, Firebase 공동 TOP 10 랭킹 지원.

## v2의 변경 사항

- 닉네임 화면 다음에 게임 전용 화면으로 전환(세로 스크롤 없이 게임 진행)
- 양쪽에서 중앙으로 다가오는 **얇은 흰 줄 두 개**
- 두 줄이 중앙에서 **자동으로 바깥으로 되돌아가는 반복 왕복**
- 중앙 목표 구간 **빨강 → 노랑 → 초록 → 노랑 → 빨강**
- 1라운드부터 5라운드까지 속도가 점점 빨라짐
- 타이밍 터치 시 해당 보호구 자동 장착 및 **자동 다음 라운드**
- 완전히 새로 그린 내장 SVG 캐릭터: 외부 이미지 파일 필요 없음, 깨진 이미지 방지
- 각 0~100점, 소수점 3자리, 최종 합산 최대 500.000점
- 마지막 보안경 착용 시 `✦ 삐싱! ✦`
- 엔딩 `모두의 안전을 지켜주셔 감사합니다`

## 중요: 업로드할 파일

이번 버전은 이미지 파일이 필요 없습니다. 다음 6개 파일만 GitHub 저장소 **최상단(root)** 에 올리면 됩니다.

1. `index.html`
2. `style.css`
3. `script.js`
4. `firebase-config.js`
5. `firestore.rules`
6. `README.md`

기존 버전 파일을 **동일한 이름으로 덮어쓰기** 하세요. GitHub에 ZIP 파일 자체를 올리는 것만으로는 실행되지 않습니다.

## GitHub Pages 설정

1. GitHub 저장소 `1125nightgame` → **Settings** → **Pages**.
2. Build and deployment: **Deploy from a branch**, branch **main**, folder **/(root)**, Save.
3. 배포된 주소는 `https://계정아이디.github.io/1125nightgame/` 형식입니다.
4. 주소를 카카오톡 단체방에서 공유합니다.

## Firebase 연결 (온라인 공용 랭킹)

1. https://console.firebase.google.com/ 에서 **Spark(무료)** 프로젝트 생성.
2. 프로젝트 설정 → **웹 앱 추가** → 생성된 `firebaseConfig`의 `apiKey`, `authDomain`, `projectId`, `appId`를 `firebase-config.js`에 입력. 사용자 계정 로그인용 **서비스 계정 키**를 넣으면 안 됩니다.
3. **Authentication** → Sign-in method → **익명(Anonymous) 사용 설정**.
4. **Firestore Database** 생성 후 **Rules** 탭에 `firestore.rules`의 내용을 붙여 넣고 **게시**.
5. GitHub에 변경된 `firebase-config.js`를 업데이트.
6. 휴대폰 두 대에서 참여한 후 랭킹을 비교하세요. `✅ 온라인 랭킹 연결 완료`가 표시되어야 합니다.

`firebase-config.js` 값이 비어 있으면 **체험 모드**로 작동합니다. 체험 모드에서는 점수가 그 휴대폰의 브라우저에만 저장되어 다른 사람과 공유되지 않습니다.

## 사용법

1. 닉네임 입력 후 게임 시작.
2. 두 줄이 중앙 **초록 구간**에 들어왔을 때 노란색 **지금 터치!** 버튼을 누릅니다.
3. 터치하면 점수와 보호구 장착이 표시된 후 다음 라운드가 **자동으로** 시작됩니다.
4. 5라운드 종료 후 합산 점수와 메시지가 나옵니다.
5. **전체 랭킹 보기**에서 TOP 10 확인.

### 점수 계산

점수가 가장 높은 순간은 두 줄이 중앙에서 만날 때입니다. 정확히 중앙이면 100점, 멀어질수록 0~100점으로 감소합니다. 소수점 3자리로 저장하므로 동점이 줄지만 완전히 없어지는 것은 아닙니다.

### 동작 및 보안 유의사항

- 동일 브라우저에서 Firebase 익명 로그인 UID를 유지하면 **최고 기록만** 갱신됩니다.
- 브라우저 기록을 지우거나 다른 기기를 사용하면 별도 익명 참가자로 집계될 수 있습니다.
- 재미로 참여하는 사내 이벤트용입니다. 점수가 클라이언트에서 계산되므로 개발자 도구로 점수 조작을 완벽하게 막을 수 없습니다.
- `firestore.rules`는 최고 점수 상승만 허용하고 점수 범위 및 인증 사용자를 검사합니다. 공식 시상 대회에는 서버 측 점수 검증이 필요합니다.
- 같은 점수의 선후 순위는 보장되지 않습니다.
- iPhone Safari, 카카오톡 인앱 브라우저, Android Chrome의 실제 화면에서 테스트하고 운영하세요.

## 속도 조절

`script.js`에서 `rounds` 배열의 `speed` 숫자를 줄이면 빠르게 움직입니다. 현재 왕복 속도는 1라운드가 가장 느리고, 5라운드가 가장 빠릅니다.
